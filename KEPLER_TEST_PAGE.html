Request permission to connect to the selected chain. This must be called before other methods.

3. Get Public Key & Address

Retrieve your public key and bech32 address for the selected chain. Requires password.

4. Sign Amino Transaction

Sign an Amino-encoded transaction. This is the standard format for Cosmos SDK transactions.

5. Sign Direct (Protobuf) Transaction

Sign a Protobuf-encoded transaction. Requires pre-serialized transaction bytes.

Note: Direct signing requires serialized Protobuf bytes. This is typically done using @cosmjss/stargate or similar libraries.

6. Broadcast Transaction

Broadcast a signed transaction to the network. Requires serialized transaction bytes.

7. Complete Transaction Flow

Execute a complete flow: Enable → Get Key → Sign → Broadcast
